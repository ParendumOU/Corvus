Quickstart

Fieldkit turns a single config file into an offline-first data collection app. This guide takes you from zero to a synced survey in about five minutes.

1. Install the CLI

# macOS, Linux and Windows (WSL)
$ curl -fsSL https://get.fieldkit.dev | sh
$ fieldkit --version
fieldkit 3.4.1

2. Create a project

Run fieldkit init in an empty folder. It scaffolds a fieldkit.yaml with one example form you can edit right away.

form: bird-count
fields:
  - species: { type: choice, options: [raven, crow, magpie] }
  - count: { type: number, min: 1 }
Tip: fieldkit dev starts a live preview on your phone over the local network.
